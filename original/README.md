# Historical CNN implementation

This folder preserves the original Cats vs Dogs CNN learning project as a historical baseline.

## Current file

- [`pet_classification_original.py`](pet_classification_original.py) — Python code extracted from the original HTML notebook export, with cell boundaries retained.

The source uses TensorFlow/Keras, image paths referenced through CSV files, a two-convolution-layer CNN, and two sequential training stages. It references `train_dog_cat.csv`, `test_dog_cat.csv`, and `train_dog_cat_kaggle.csv` alongside their image files.

## Preservation policy

The original Python file is intentionally kept unchanged. It has **not** been execution-tested during this repository review, and the code's training configuration should not be mistaken for verified results. Modernized code and reproducible evaluation will be developed separately.

The historical HTML export may be added after reviewing its contents and redistribution rights.
